ТВОЯ РЕКЛАМА — готовий сайт (попередня версія)

ПЕРЕГЛЯД: відкрийте index.html у браузері. Для коректного завантаження змін із content.json краще використовувати локальний сервер або опублікований сайт.

ЩО ВЖЕ ГОТОВО: адаптивний сайт, усі послуги, 18 фото робіт, контакти, фільтри портфоліо, перегляд фотографій.

ЯК САМОСТІЙНО РЕДАГУВАТИ ПІСЛЯ ПУБЛІКАЦІЇ:
У комплекті є Decap CMS: /admin/. Щоб редактор запрацював, потрібен GitHub-репозиторій, хостинг (наприклад Netlify) та налаштування GitHub OAuth для Decap CMS. У файлі admin/config.yml замініть REPLACE_WITH_REPOSITORY на власник/репозиторій. Сам по собі файл admin/index.html ще не дає можливості увійти: авторизацію треба налаштувати під час публікації.
Після налаштування редактора можна додавати фотографії, міняти тексти, телефони та послуги без програмування.

Поки редактор не підключений, можна змінювати content.json у текстовому редакторі та додавати фото в assets/; після цього потрібно оновити файли на хостингу. Не видаляйте index.html.

ВАЖЛИВО: кнопка Telegram з номером може працювати не у всіх клієнтів Telegram (залежить від налаштувань приватності). Для надійного зв'язку краще надати публічне Telegram-ім'я користувача, яке можна додати як окреме посилання. Viber працює через застосунок.

Для реального запуску знадобиться домен і хостинг. Наразі сайт НЕ опублікований в інтернеті.
